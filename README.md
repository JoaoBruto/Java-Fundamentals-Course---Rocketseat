# ☕ Java — Estudos e Anotações

Repositório criado para registrar minha evolução durante os estudos de **Java** através do curso da **Rocketseat**.

Aqui estão reunidas minhas anotações, exercícios, exemplos e práticas realizadas durante o aprendizado da linguagem, desde os fundamentos da sintaxe até conceitos de **Programação Orientada a Objetos (POO)**.

## 🎯 Objetivo

Construir uma base sólida em Java, entendendo não apenas a sintaxe da linguagem, mas também os principais conceitos utilizados no desenvolvimento de aplicações.

O foco inicial é dominar os fundamentos e, posteriormente, avançar para conceitos mais complexos da linguagem e do desenvolvimento de software.
